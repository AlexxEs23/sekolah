🏫 Website Manajemen Sekolah
Website Manajemen Sekolah ini merupakan aplikasi berbasis web yang dikembangkan menggunakan PHP Native tanpa framework. Aplikasi ini dirancang untuk membantu sekolah dalam mengelola data penting seperti siswa, guru, dan mata pelajaran secara efisien dan terpusat.

✨ Fitur Utama
📋 Manajemen Data Siswa
Tambah, ubah, dan hapus data siswa seperti nama, NIS, kelas, dan informasi lainnya.

👩‍🏫 Manajemen Data Guru
Input dan kelola data guru termasuk NIP, nama lengkap, dan mata pelajaran yang diajar.

📚 Manajemen Mata Pelajaran
Tambahkan dan atur daftar mata pelajaran serta keterkaitannya dengan guru.

🔐 Autentikasi Login
Sistem login sederhana untuk membatasi akses hanya bagi pengguna yang memiliki akun.

💻 Teknologi yang Digunakan
Bahasa Pemrograman: PHP Native

Database: MySQL

Frontend: HTML, CSS, JavaScript

Tools Pendukung: XAMPP / Laragon (untuk local server)

🎯 Tujuan
Aplikasi ini dikembangkan untuk mendukung proses digitalisasi data sekolah, menggantikan pencatatan manual, serta memudahkan staf administrasi dalam mengelola informasi penting secara cepat, aman, dan terorganisir.
